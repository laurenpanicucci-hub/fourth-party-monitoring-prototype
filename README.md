# 4th party monitoring prototype

Grayscale research prototype for a third party risk tool: a vendor portfolio with a deduplicated subprocessor view, a supply chain map, and a 4th party monitoring page that walks through a real supply chain incident (Salesloft Drift, reached through Cloudflare) as a single advisory updated over time.

Open `index.html` in a browser. Everything is in the one file.

Moderator controls: the state inspector at the bottom left steps the timeline (Aug 20, Aug 23, Aug 26). Press `m` to hide or show it.
